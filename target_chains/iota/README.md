# Pyth on IOTA

This directory contains the Pyth contract for IOTA and utilities to deploy and use it.

- `cli` folder contains tools for deploying and upgrading the Pyth contract.
- `contracts` folder contains the Pyth contract source code in Move.
- `sdk` folder contains the Pyth javascript SDK for IOTA that should be used by dApp developers.

For more information regarding Pyth integration on IOTA please refer to our [docs](https://docs.pyth.network/documentation/pythnet-price-feeds/iota).
